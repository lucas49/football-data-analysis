## Key Findings

The analysis of 380 Premier League matches from the 2025/26 season revealed that three goals was the most common total, occurring in 101 matches (26.58%).

Additionally, 66.05% of matches finished with between two and four goals, inclusive. In contrast, only 4.21% of matches had six or more goals.

These findings suggest that matches with a moderate number of goals were much more common than high-scoring matches in this dataset. However, these results describe one season and should not be assumed to predict future seasons.
